# Выдуманный пример shop_demo

Оба ZIP содержат одну и ту же выдуманную БД: 4 таблицы, 17 строк. Схема и данные созданы с нуля, без реальных исходных данных.

- `shop-demo-ydb-original.zip`: учебные scheme.pb и URL-encoded CSV плюс учебные метаданные. Это локально собранный пример формата, а не экспорт из живой YDB.
- `shop-demo-postgresql.zip`: результат запуска конвертера над первым примером; SQL для psql и pgAdmin, схема, отчёты и манифесты.

Проверены значения всех полей, количество строк, ключи и целостность архивов. Импорт в серверы YDB/PostgreSQL не выполнялся. SHA256 — в `SHA256SUMS`.

Генератор: `python3 tools/build_examples.py --output ./work/demo-build` из корня репозитория, в новую папку.
